1.0.2 已复现并修复 `generate if ... always @(*) ... if ... begin` 的 `unmatched begin` 误报。新增覆盖无 begin 的条件分支、else-if、generate-case、for 中的条件分支、分支外实例、被跳过分支原文及其引用的模块定义保持不变。真正缺失 end 的输入仍会拒绝，并报告阶段链、连接、文件行列、模块和源码 caret。verbose 模式已验证不污染 map JSON。
