| 检查 | 结果 |
| --- | --- |

测试集合包含 42 项命令行测试、29 项路由测试、20 项解析测试和 11 项事务测试。失败注入验证了写入失败回滚；增删改测试验证了删除最后一条连接后恢复原始字节。

1.0.3 取消了建图和连线过程对接口/modport 端口列表、重复端口名和重复连接名的合法性检查；这些内容按源码保留，交给用户工程的编译器处理。新增覆盖一个 port list 中多个 interface/modport 端口、接口数组和重复连接项。`generate if ... always @(*) ... if ... begin` 的边界修复、阶段链、源码 caret 与 verbose 日志验证继续保留。

本机未安装 Icarus Verilog，因此未执行 Icarus 测试分支；使用上述 slang 检查生成的 SystemVerilog。未在 Python 3.8 解释器实际运行，语法检查不等同于对应版本运行验证。

该记录针对随项目交付的样例和回归用例，不代表用户实际 RTL 工程已完成仿真、综合或时序验证。复现方式见 `test/README.md`。
