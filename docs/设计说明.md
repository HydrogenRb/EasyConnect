# EasyConnect 1.0 设计说明

## 从需求到实现

RTL 的模块定义关系是图，按例化路径展开后才能得到具体实例树。同一模块在两处例化时，修改其 `.v` 定义会同时改变两处硬件。EasyConnect 先构建保留源码位置的模块图，再构建带完整路径的实例树，在实例树上寻找最近公共祖先（LCA）。

过程块不参与该分析。`always` 家族及 `initial` / `final` 仅匹配语法边界并整体跳过，不提取内部赋值或驱动信息，也不改写内部原文。驱动保护仅覆盖声明初始化、连续赋值、子模块端口连接等结构上可见的情况；过程驱动交给用户工程编译器检查。

“开始、链接、转向、结束”是同一条路径的四种角色，不必维护 24 套互不关联的文本插入规则。例化类型决定边的处理方式，路径角色决定信号流向。

| 例化情况 | 开始 | 链接（上/下） | 转向（公共祖先） | 结束 |
| --- | --- | --- | --- | --- |
| 普通实例 | 现有信号通过辅助 output 导出 | output 向上、input 向下 | 声明 wire，将两侧接到同一个信号 | 绑定 input，或通过辅助 input 驱动未驱动的内部信号 |
| CBB，无源码 | 按元数据绑定已有 output；已连接输出保留原连接并读取其信号 | 不穿过黑盒未知内部层级 | 在有源码的父模块中完成 | 按元数据绑定已有 input |
| 同模块多实例，共享信号 | 保留原始源 | 必要时生成选中实例的专用模块副本 | 多条连接可以读取同一源 | 分别连接各实例，形成 fanout |
| 同模块多实例，不同信号 | 按完整实例路径选择 | 专用副本隔离模块定义修改 | 每条连接独立命名 | 各目标实例保持独立 |
| for 循环，共享信号 | 普通源可以广播；生成族 output 不能共享驱动一个 net | 在符号路径上修改整个生成族 | 使用同一父级信号 | 每次例化连接相同信号 |
| for 循环，`signal[i]` | 按 lane 导出 | 经过循环边界增加/去除 lane 维度 | 使用 lane 数组 | 在例化处使用 `[i]`，嵌套为 `[i][j]` |

CBB 没有可修改的内部源码，所以其“开始”和“结束”只涉及现有接口；不能替未知 IP 发明端口。模块实例数组、条件生成、某个具体生成 lane 的单独特化都涉及进一步 elaboration，本版明确拒绝。

## 信号形状

信号类型由 packed 范围、unpacked 范围和 signedness 一起决定。例如：

```systemverilog
wire signed [`DATA_W-1:0][1:0] payload [0:`ROWS-1][0:`COLS-1];
```

其中两个 packed 维度始终位于变量名前，两个 unpacked 维度始终位于变量名后。辅助端口和中间 wire 使用同一形状，不把数组压平成总位宽。宏表达式保留原文；命名参数覆盖和 localparam 引用在跨模块前解析到常量/宏表达式，防止把子模块的局部 `W` 写到父模块。

indexed 模式自动从已有端点形状推导 lane 放在 packed 还是 unpacked 侧。常见 `enable[N-1:0]` 的每位可以接到单独实例；每 lane 的多维 memory 则用外层 unpacked 维度。工具不做隐式截断、补位或维度重排。

## 修改和撤销

源码解析记录原文字符偏移。改写在内存中规划并重新解析，通过后才写入；注释及未受影响区域保持原样。新增端口、线网和赋值使用 `__ec_<连接ID>` 前缀，必要时自动避开已有名称。业务信号名可以在两端不同，中间连接由公共祖先中的 wire 完成。

第一次修改保存 UTF-8 原始字节快照；每次增删改都基于该快照按顺序重放当前连接集合。因此支持先删除较早的连接，且删除最后一条时恢复原始文件，包括 BOM、CRLF 和末尾换行。

该版本采用保守的外部修改保护：受管期间一旦人工编辑 RTL，下一次管理操作会拒绝覆盖。它不会通过猜测文本位置删除用户的新代码。多文件写入有日志、独占锁、逐文件原子替换和失败回滚；崩溃后的事务可以通过 `recover` 恢复。

## 验证边界

词法解析和形状检查不等于完整编译，更不等于功能仿真。基础测试只用标准库，另外可选择调用 slang 对生成 RTL 做独立语法、类型和 elaboration 验证。没有用户实际工程的编译文件表、宏配置、约束和 testbench，本项目不会声称已验证用户工程的综合时序或业务功能。
