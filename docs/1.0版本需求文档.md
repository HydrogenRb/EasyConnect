# 基本描述
我目前有一个rtl文件，其中嵌套文件夹有非常.v文件，这些代码互相例化，构成了“一棵树”，但是有的信号要上下很多次，这非常麻烦，我希望有一个脚本，能让复杂的操作变成简单的一键操作。
例子是
假设一个例子，A中有B，B中有C，A中有D，如果我要拉一根线从C到D，我需要在C.v中新建output，并链接逻辑；在B.v中新建output，并链接到C的例化；在A.v中创建wire，并链接到B和D的例化；在D中创建input并链接到逻辑。
这个情况太复杂了，我希望让我的操作简化成 python EasyConnect.py add U_C.fifo_rd U_D.fifo_rd_in (这个换名字，应该在A.v中做，A.v中有 .fifo_rx(w_fifo_rd) ....   .fifo_rd_in(w_fifo_rd))
拓展来说，这个操作应该针对增删改这三种情况

# 输出闭环
你应该输出至少三个脚本，脚本1处理建图功能，脚本2处理连线功能，脚本三叫做easyconnect将用户输入变成另外两个脚本的输入，用户（命令行窗口）的入口只有easyconnect；
脚本应该保持0依赖或者尽量少的依赖，从而保证兼容性；

# 系统输入输出
在建图模式中：输入rtl文件夹位置和顶层模块的名字，输出符合要求的json文件
```text
python EasyConnect.py 1 [rtl folder] [TOP_LEVEL_MODULE]
```
在连线模式中：输入json文件等
```text
python EasyConnect.py 2 [json file] {add|rm|mv} <src module>.<sig name> <dst module>.<sig name> [-d] [dimension] [-w] [width] [-c] [comment]
```
输出是直接修改对应位置的代码

# 功能分解
## 建图功能
本功能会扫描当前rtl文件夹位置，分析其中文件架构，输出json文件；这个功能实现的时候应该考虑到真实System Verilog项目的编译流程；
当前项目文件夹的test_cases/case1/expected_hierachy.json中展示了示例的json输出；1.0版本中，每个instantiations都应该有module instance style status；
在1.0版本中，其中style和status都是normal，不需要额外解析for循环，不需要管使用哪种方式调用input和output；
每一个instantiations应该额外记录：模块的input和output部分的开头和结尾行号，例化的模块的开头和结尾行号；
### 第一步：搜索文件
首先，遍历递归搜索当前文件夹中的所有.v和.sv文件，记录其中module xxx中的模块名，我们之后的操作都仅限于这些模块。
### 第二步：创建包含关系、行号
文件中，扫描其他项目，以第一步搜索到的模块名，分析其例化名；
同时，需要分析行号；
进行这一步的过程中，请考虑到
1.有的信号没有#()语法的parameter
2.所有信号都使用.(sig)sig来生成信号
### 第三步：创建json
按照上面规则创建json，对于代码中的其他模块，不做分析、不做思考；
## 连线功能
有4种链接：开始、链接、转向、结束。在树状图中（根在上，叶在下）开始是开始，结束是结束，链接是信号往上或者往下，转向是信号在同层平移（比如基本描述中A.v中的操作）；
当前，我们只有从一个模块连接到另一个模块的模型模型的情况，开始和结束的点可能是唯一的（全局只例化了一次）也有可能是不唯一的（总之是例化了多次）
**这个部分，每一步要如何做，我没想好，plan mode中我们一起探讨这个如何工作；我当前的想法是：对于多次例化的情况，脚本会交互式地询问每一层是否需要1.保持原样 2.选择分开，如果分开，则会将一部分代码安排给其他例化**
**考虑到我们的目标是修改代码，所以我们的操作应该针对module名而不是例化名**
**我们先不考虑如果同一个模块在不同子模块中被例化的情况**
我们在生成的时候默认1维1位宽信号，但是用户可以指定多维，生成多维度的时候应该按照这样的逻辑
```verilog
input [a -1:0][b -1:0] sig, //可定制注释
//位宽后面一个空格-1:0，维度都在信号名前面
```
用户的sig_name可以带有方括号；
用户可以要求-c，给每一个生成的后面加入定制的注释。
如果信号的src名和dst名不一致，则这个名字应该在"转向"的部分修改，比如
文件1伪代码
```verilog
module M_1
output src_name;
sub_module U_SUB_MODULE (.src_name(src_name))
```
文件2伪代码
```verilog
module M_2
input dst_name;
sub_module U_SUB_MODULE (.dst_name(dst_name))
```
文件top伪代码
```verilog
wire w_src_name;
M_1 U_M1(.src_name(w_src_name));
M_1 U_M2(.dst_name(w_src_name));
```
